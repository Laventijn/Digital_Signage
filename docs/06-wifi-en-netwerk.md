# Wifi En Netwerk

Gebruik bij voorkeur bekabeld netwerk voor vaste schermen. Wifi kan gebruikt worden wanneer bekabeling niet mogelijk is.

## Controle

```bash
scripts/show-network-info.sh
scripts/check-network.sh
```

## Aandachtspunten

- Zorg dat DNS werkt.
- Controleer captive portals.
- Voorzie stabiele DHCP-reserveringen waar nodig.
